# ADR-002: Exact schema parity, and the type mapping used

**Status:** Accepted (Sprint S00, tasks F-03 / F-04 / F-05)

## Decision

61 application tables are reproduced in Postgres with identical table names,
column names and **column order**. `tools/verify_parity.py` fails the build on
any drift.

> Note: earlier planning documents said "62 tables". The 62nd object was
> `sqlite_sequence`, a SQLite internal. The real count is **61**.

## Type mapping

| Laravel / MySQL | Postgres | Rationale |
| --- | --- | --- |
| `int` primary key | `bigint GENERATED BY DEFAULT AS IDENTITY` | Preserves explicit-id inserts during migration. |
| `int` | `bigint` | |
| `varchar` | `varchar(n)` | Lengths read from the migrations, not guessed. |
| `text` / `mediumText` | `text` | |
| `tinyint(1)` | `smallint` | **Not `boolean`.** The app compares against `0`/`1` in hundreds of places. |
| `double(10,2)` | `numeric(10,2)` | MySQL rounds these to 2dp on store; `double precision` would not. |
| `float` | `double precision` | Declared without precision in the source. |
| `decimal(10,2)` | `numeric(10,2)` | |
| `datetime` | `timestamptz` | App timezone is UTC, so the conversion is lossless and this avoids a class of DST bugs. |

## JSON-as-text columns

Twenty columns hold JSON inside `text`. They stay `text`. Promoting them to
`jsonb` would be a schema change and would alter the bytes on the wire.

Consequence: `JSON.stringify` is **not** safe for these columns. PHP's
`json_encode` escapes forward slashes (`/` becomes an escaped solidus) and emits
non-ASCII as `uXXXX`. `phpJsonEncode`/`phpJsonDecode` in `@onyx/core` reproduce
that exactly, and `test/php-json.test.ts` asserts byte-identical round trips --
including `live_classes.additional_info`, which stores Zoom URLs and is the case
plain `JSON.stringify` silently corrupts.

## Foreign keys

Laravel enforced relationships in application code, not with database
constraints. We keep it that way. Adding FKs now would reject legacy rows that
already violate them and turn a data-quality problem into an outage.
