Onyx Learn — everyday learning

6 features shown below, all working

Browse and join courses

Working

Every course the institution offers is listed in one place. Depending on how a course is set up, a learner can join it straight away, pay to unlock it, or be added directly by the institution. Tried live: a real course, joined during this check.

A learner's course list

Video, reading and document lessons

Working

A course can mix videos, documents, images, links and plain written pages. Every lesson — not just video — remembers exactly where a learner stopped.

An actual lesson, mid-way through

Attendance, by QR code or by hand

Working

A teacher opens a live session and a QR code appears that learners scan with their own phone. The code changes every 15 seconds, so a photo of it stops working within half a minute. Attendance can also be marked by hand.

A live session, with the rotating check-in code on screen

Homework: set it, mark it, hand it back

Working

Teachers set homework with a marking guide attached, learners submit their work online, and it comes back marked with a score and written feedback.

Real homework, handed in, marked and scored

One screen: what to do next

Working

Every learner gets a personal home screen built around “what should I do right now” — the course they were last on, homework due, a day streak, and a readiness score with a plain reason behind it.

A learner's own home screen

Ask a question, get a real answer

Working

Learners can ask a question on any course. If it goes unanswered, it can be turned into a formal support ticket with its own deadline.

A learner's own list of support tickets

Onyx Code Lab — learning to code

5 features shown below, all working

Write and run real code, in the browser

Working

No software to install: a learner writes code directly in the browser and sees the program's real output immediately.

The in-browser code editor, open on a real problem

Code runs safely, every time

Working

Every submission runs in a locked-down space that cannot reach the internet or affect anyone else's work — confirmed by deliberately trying to break out of it.

Real code, actually executed, with the real result shown back

Marked automatically, instantly

Working

A submission is tested against prepared cases — some shown, some hidden — with partial credit and instant feedback on exactly what happened.

The same problem, graded the instant it was run

A library of practice problems

Working

Problems are organised by difficulty and topic, with hints available for a small cost and worked solutions that unlock once a learner has earned them.

The practice bank, filterable by difficulty and topic

Real, multi-file coding projects

Working

Beyond a single problem, a learner can start a full project with a save-point button, and their teacher can open it and leave comments.

A learner's own project workspace

Onyx Assess — tests and exams

4 features shown below, all working

Scheduled, timed online tests

Working

Tests are timed by the server, not the learner's device, and drawn from randomised question banks so the class doesn't all sit an identical paper.

A learner's list of tests: open, closed, or being marked

Exam integrity, watched and reviewed

Working

For exams that need it, the camera and screen are monitored and anything unusual is flagged for a real person to review. A flag is evidence, never an automatic fail.

The live integrity console a teacher watches during an exam

Marking: automatic where possible, by hand where it matters

Working

Multiple-choice questions are marked instantly. Written answers are marked by a teacher against a guide, with an optional second check before results go out.

A teacher's marking queue, with real papers waiting

Results, the moment they're released

Working

Once released, a learner sees their score and grade in one place, alongside how the class did overall — invisible to them until that moment.

A learner's own results page

Onyx Career — getting a job

5 features shown below, all working

Live coding contests

Working

The institution can run a timed coding contest with a leaderboard and team entry, judged automatically by the same safe system used for everyday practice.

A live contest, entered and being judged

Practice job interviews

Working

A mock interview can be booked, scored against clear criteria, and optionally recorded with consent. The interviewer's private notes are never shown to the learner.

A learner's own interview screen
The same feature, employer side

Certificates anyone can verify

Working

A learner who completes a course gets a certificate with a unique code. Anyone can look it up on a public page, no account needed, and see if it's genuine.

The certificate register — one freshly issued
That certificate's public page, no login

Jobs, applications and employers

Working

Employers post roles, learners apply, and the placement office manages it all. Each employer only ever sees their own applicants — never another company's.

A learner's own job applications
The same role, employer side

A profile built for employers

Working

Every learner gets a shareable profile and a one-click resume builder that assembles a PDF from their actual record, so it can never go stale.

A learner's own profile
The resume it builds, from that record
