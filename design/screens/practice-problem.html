Longest Substring Without Repeating Characters

Medium, Strings, 2000 ms and 256 MB per case · 4 attempts so far

Save Ask a mentor
Medium Strings Sliding window Hashing

Given a string s, return the length of the longest substring of s that contains no repeated character.

A substring is a contiguous run of characters. In "pwwkew" the answer is 3, for "wke" — "pwke" is a subsequence, not a substring, so it does not count.

Read the string from standard input and print a single integer.

class Solution:
    def length_of_longest(self, s: str) -> int:
        """Sliding window: left edge never moves back."""
        seen = {}      # character -> last index seen
        start = 0
        best = 0

        for i, ch in enumerate(s):
            if ch in seen:
                start = seen[ch] + 1
            seen[ch] = i
            best = max(best, i - start + 1)

        return best
